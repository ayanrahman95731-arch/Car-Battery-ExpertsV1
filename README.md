# Car-Battery-ExpertsV1
800 BATTERY EXPERTS - ANDROID PWA INVOICE APP
=============================================

Included Files:
1. index.html           - Complete offline-ready UAE Tax Invoice web app
2. manifest.webmanifest - Android/iOS PWA app manifest (relative paths for GitHub Pages & Netlify)
3. sw.js                - Service worker for offline caching & fast mobile startup
4. icon.svg             - Vector app icon

How to Host & Install on Android (Phone Only):
1. Extract this ZIP file on your Android phone.
2. Open Chrome on Android, go to https://github.com, enable "Desktop site" in Chrome menu, and create a new Public repository.
3. Upload index.html, manifest.webmanifest, sw.js, and icon.svg to the root of the repository and commit.
4. Go to repository Settings -> Pages -> Deploy from branch: main / (root) -> Save.
5. Open your https://<username>.github.io/<repo>/ link in Android Chrome, tap the 3-dot menu, and tap "Add to Home screen" or "Install app".
